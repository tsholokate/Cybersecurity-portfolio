# Linux, Security Tools & Reconnaissance

## Project Overview

This project documents my practical learning and hands-on exercises in Linux fundamentals, security tools, and network reconnaissance.

The activities were completed using Ubuntu Linux through WSL (Windows Subsystem for Linux).

## Activities Completed

### Activity 1 – Linux File and Directory Management
- Navigating Linux directories.
- Creating, copying, moving and deleting files.
- Managing files and directories through the terminal.

### Activity 2 – Linux Users and Groups
- Identifying the current user.
- Inspecting user and group information.
- Understanding Linux account management.

### Activity 3 – Linux Processes and System Monitoring
- Inspecting running processes using `ps`.
- Monitoring system resources using `top`.
- Checking system uptime and process information.

### Activity 4 – Linux Security Basics
- Inspecting file permissions.
- Understanding Linux permission values.
- Changing permissions using `chmod`.
- Examining file ownership and metadata using `stat`.

### Activity 5 – Linux Privilege Management and Security Inspection
- Inspecting sudo privileges using `sudo -l`.
- Understanding file ownership using `chown`.
- Examining default permissions using `umask`.
- Searching for files and inspecting permissions using `find`.

### Activity 6 – Passive and Active Reconnaissance
- Inspecting network interfaces using `ip addr`.
- Examining routing information using `ip route`.
- Understanding DNS reconnaissance.
- Using `dig` and `nslookup` to investigate DNS records.
- Examining A, MX, NS and TXT records.

### Activity 7 – Network Scanning and Enumeration with Nmap
- Installing and verifying Nmap.
- Performing basic port scans.
- Scanning specific TCP ports.
- Performing service and version detection using `-sV`.
- Conducting host discovery using `-sn`.
- Discovering hosts within a subnet.
- Performing operating system detection using `-O`.

## Tools and Technologies

- Ubuntu Linux
- Windows Subsystem for Linux (WSL)
- Linux Terminal
- Nmap
- dig
- nslookup

## Key Learning Outcomes

Through these practical exercises, I developed foundational skills in:

- File permissions and privilege management.
- User and group administration.
- Process and system monitoring.
- DNS investigation.
- Network reconnaissance.
- Port scanning and host discovery.
