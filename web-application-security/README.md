# Web Application Security

This folder contains learning notes and practical assessment evidence for the Web Application Security module.

## Project contents

- `Web-Application-Security-Learning-Documentation.md` — consolidated foundations notes and practical assessment documentation.
- `screenshots/` — screenshots supporting the practical activities and security observations.

## Lab environment

The practical exercises were carried out in a local OWASP Juice Shop training environment, with OWASP ZAP and browser developer tools used for testing and observation.

> Assessment notes should distinguish confirmed observations from tests where no execution or security impact was demonstrated.
