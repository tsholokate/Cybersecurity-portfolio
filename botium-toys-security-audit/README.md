# Botium Toys — Internal Security Audit

## Scenario
Botium Toys is a small U.S.-based toy company with a growing online presence 
in the U.S. and E.U. As the business scales, the IT manager needs to ensure 
compliance and secure the company's infrastructure. This project involved 
conducting an internal audit using the NIST Cybersecurity Framework (NIST CSF) 
to assess risks, threats, and vulnerabilities to critical assets — including 
compliance requirements for online payments and E.U. business operations.

## Task
Reviewed the IT manager's audit scope, goals, and risk assessment report, 
then completed a controls and compliance checklist to evaluate the company's 
security posture.

## Approach
- Applied the NIST CSF framework to structure the audit
- Assessed existing controls against compliance requirements (PCI DSS for 
  payment processing, GDPR for E.U. operations)
- Identified gaps between current security posture and required controls
- Documented findings in a controls and compliance checklist

## Key Skills Demonstrated
- Security auditing methodology
- NIST CSF framework application
- Compliance awareness (PCI DSS, GDPR)
- Risk assessment and documentation
