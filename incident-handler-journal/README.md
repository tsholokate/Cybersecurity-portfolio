# Incident Handler's Journal

## Project Overview

This project contains my Incident Handler's Journal completed as part of the Google Cybersecurity Professional Certificate. It documents incident investigations, security tool usage, and personal reflections while applying the NIST Incident Response Lifecycle.

## Objectives

- Document cybersecurity incidents
- Apply the 5 W's of incident investigations
- Record the use of cybersecurity tools
- Practice professional security documentation
- Reflect on learning and incident response processes

## Skills Demonstrated

- Incident Documentation
- Incident Response
- Security Analysis
- NIST Incident Response Lifecycle
- Log Analysis
- Network Traffic Analysis
- Professional Technical Writing

## Tools Used

- Wireshark
- Suricata
- Splunk
- Google Chronicle
- VirusTotal

## Contents

- Incident Handler's Journal (PDF)
- Incident investigations
- Tool documentation
- Learning reflections

## Conclusion

This project demonstrates my ability to document cybersecurity incidents, analyze security events, use industry-standard security tools, and communicate findings using professional documentation practices.
